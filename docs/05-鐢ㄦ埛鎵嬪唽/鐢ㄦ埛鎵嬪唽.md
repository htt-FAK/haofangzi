# 用户说明手册

**系统**：肇庆市"好房子"在线选房与户型智能评估系统 v1.0　**读者**：购房者、销售顾问、系统管理员
**注意**：本系统为课程设计演示系统，评分与结论文字**仅供参考，不构成购房或投资建议**；数据均为构造样例。

---

## 一、快速上手（购房者，3 分钟主路径）
1. 打开 `http://<演示地址>/` → 首页顶部按 **区域 / 面积 / 居室 / 总价** 筛选 → 卡片即为可评估的户型。
2. 点任一卡片右下角 **评分徽标**（未评分显示"评估"）→ 进入"户型详情"。
3. 详情页四个 Tab：**2D 图纸**（点房间看参数）、**3D 空间**（拖动旋转、滚轮缩放、"漫游"按钮 WASD 行走）、**720° 全景**（拖拽+热区切房间）、**参数表**。
4. 点右上 **评估此户型** → 结果页看总分/等级、7 维雷达、点开任一维看"我的值 / 阈值 / 得分 / 依据"；顶部下拉可切换人群模板（三口/四房/三代/退休/投资）。
5. 收藏 2~4 个户型 → 右上 **加入对比** → 对比页 → **导出报告(PDF)** 或 **生成分享链接** 发给家人。
6. 满意后在房源列表点 **模拟选房**（需登录）→ 确认页二次确认 → 10 分钟锁定 → **转意向** → **预约看房**（选时段、人数）。

> 演示账号：`13800000001 / Test@123`。首次登录有"完善画像"引导（4 步），完成后才解锁 AI 选房顾问。

## 二、注册、登录与画像
| 操作 | 步骤 | 常见问题 |
| --- | --- | --- |
| 注册 | 登录页 →"注册"→ 手机号 → 图形码（算术题）→ 口令（≥8 位字母+数字，有强度提示） | "该手机号已注册"= 已存在，直接登录 |
| 登录 | 口令 或 短信码（演示环境固定 `123456`，真实接入后为一次性 6 位） | 连续 5 次失败锁 15 分钟，倒计时在页面可见 |
| 完善画像 | 头像 → 购房画像：预算区间 / 家庭结构 / 最少居室 / 偏好朝向 / 偏好标签（≤5） | 完整度 <60% 时列表不会自动带入筛选、顾问入口灰 |
| 改密 / 注销 | 设置 → 修改口令（旧密必填）；注销后数据匿名化，评测历史仍计入统计 | 注销不可恢复 |
| 退出 | 头像 → 退出登录 | 令牌 2 小时过期，会静默续期一次 |

## 三、看户型：2D / 3D / 全景 / 参数表
- **2D 图纸工具条**：`面积` / `尺寸` / `无标注` 三档切换；右下角指北针（默认"下=南"）与比例尺；缩放按钮或 `Ctrl+滚轮`；点击房间 → 右侧显示该间长宽、面积、窗面积、窗地比。
- **3D 空间**：`俯视`模式拖动旋转；`漫游`模式点开始后 WASD 行走（视角高 1.6m，Esc 退出）。加载失败或 3 秒未完会自动回落为 2D 图，不会白屏。
- **720° 全景**：鼠标拖拽转视角，滚轮放大，双击全屏；房间名热区跳转视点。无全景素材的户型该项不可点。
- **参数表**：21 项指标值 + 得房率/朝向/面宽进深等，底部有"尺寸与参数来自公开资料整理，实际以交付标准与现场实测为准（误差 ±5%）"的提示。
- **楼层剖面**：显示总层数、本层、每层户数、电梯数量与前方遮挡示意，帮助判断低楼层采光。

## 四、在线选房与规则（重要）
1. 筛选后可切"楼层矩阵"直接选楼层房号；也可在"我的收藏"里集中比较。收藏上限 50 条（超出时提示清理，重复收藏不会占额度）。
2. **模拟选房**是**教学演示用**的临时锁定，不是认购、不产生任何费用或合同义务：
   - 有效期 10 分钟，可"续期"2 次，累计不超过 20 分钟；
   - 关闭页面不影响锁定，倒计时归零后自动释放，并给你站内通知；
   - 若房源被别人抢先锁定，会提示"已被锁定"并给同户型相邻楼层的备选（可直接切换）。
3. **转意向**：锁定成功后点"转意向单"→ 房源变"已预留"并保留 24 小时，意向号 `YXyyyyMMddxxxxxx` 可在预约时引用。
4. 销控状态含义：`可选` / `锁定中`（含剩余秒数） / `已预留`（你的意向） / `已售`。

## 五、看懂评估结果
| 元素 | 含义与读法 |
| --- | --- |
| 总分与等级 | 100 分制，≥85 优 / 75 良 / 60 中 / <60 差；等级只用于快速排序 |
| 7 维雷达 | 采22 通18 动线16 实用16 静谧10 绿色8 经济10（权重之和=1，模板可改） |
| 指标明细 | 每行：指标名 / 我的值 / 判定表达式（如 `0.158 ≥ 0.140`）/ 档位 / 得分 / 维度贡献 / 依据条文编号 |
| 数据不足 | 灰行 + "—"，维度会按有效指标归一，**不会因缺数据扣你分**；但请留意缺失项数量提示 |
| 改进建议 | 按"分值提升潜力"排序的前 3 条，来自规则里配置的建议模板，不是模型猜测 |
| 免责 | 结果基于规则与样例参数，不能作为合规验收质量结论 |

## 六、对比报告：生成、导出与分享
1. 在候选池勾选 **2~4 个**（1 个不能对比，5 个会提示上限）。缺评估记录时系统会先自动补算再对比。
2. 对比页读法：**绿色↑＝该行最优**，红色↓＝最差，右侧显示与第二名的差；比率行看绝对差，金额行看百分比。
3. 结论卡顶部标注 `AI 生成` 或 `模板生成（AI 暂不可用）`；结论中的每条理由都带可点击指标编号，点了会跳到对应行。
4. 导出 PDF：A4 两页（P1 结论+雷达+摘要表，P2 明细+依据）。浏览器打印也可（用网页自带打印样式）。
5. 分享：生成只读链接，默认 **7 天**；可在"我的报告"里 **撤销**（链接立即失效 40304）。分享页不含你的手机号。
6. 重新打开报告用的是**创建时**的规则版本快照，因此规则升级后历史报告分数不变（页眉会写"基于规则 vN"）。

## 七、AI 选房顾问
- 入口：主页顶部"AI 顾问"（画像完整度 ≥60% 后解锁）。
- 工作方式：系统先按你的硬条件（预算、最少居室、在售）筛出候选，再由大模型在候选内排序并写理由 —— **不会推荐已售房源，也不会给你编新的分数**。
- 每张卡：推荐理由（3 条带指标编号）、需要注意（2 条）、下一步建议；底部有"这套为什么不行"与追问输入框（单轮）。
- 断网或额度用完时会出现黄条"当前为模板结果"，功能仍可用。
- 所有结论仅供选房参考，不构成投资建议。

## 八、预约看房（购房者侧 / 顾问侧）
**购房者**：预约向导 4 步（对象 → 日期时段 → 联系方式 → 确认）；灰位＝已满；提交后状态 `待确认`；
顾问确认变 `已确认`，看房前 1 天与提前 2 小时会收到通知；可在"我的预约"里 **改期**（回到待确认并重新占位）或 **取消**（选原因）；
已到访或已完成后不能再取消。
**顾问 / 管理员**：`后台 → 预约管理`（日历视图 + 列表视图）。操作：`确认`、`改约（可改时段）`、`标记到访`（可用手机号后 4 位或意向单号核对）、`完成`（填跟进结果与关注标签，会回写客户画像）、`取消`。
顾问只能看到自己名下客户，手机号一律脱敏；`导出明日清单(Excel)` 同样脱敏。`时段容量` 页可改每段接待上限或临时停用（如样板间维护）。

## 九、管理员：数据维护与规则管理
1. **楼盘/楼栋**：基础信息 + 经纬度（可手填，演示不依赖地图）+ 南向遮挡系数。
2. **户型与房间构件**：先填主参数（面积、朝向、面宽/进深/净高、窗面积等），再逐间录入"类别 + 位置 x/y + 宽 x 高 + 窗面积"。
   保存时自动校验：坐标越界（提示第几间）、面积与坐标不一致 >5%、房间面积和 ≠ 套内 >3%、窗大于墙。任一失败按行内红框显示，改完再提交。
   素材上传：SVG 户型图、GLB 模型（可无，用参数化 3D）、全景图（可无）。
3. **评估规则**：规则集列表 →「复制为草稿」→ 在"权重/分档/AI 草案"三处调整。
   - 权重：滑块实时显示总和，`≠1.000` 时禁止发布；
   - 分档：可改区间与分值，必须有序不重叠；依据文本必填（这是可解释性的来源）；
   - AI 草案：输入一句诉求（如"三代同堂、重视通风、预算 150 万内"）→ 生成 diff 表 → 逐条采纳/忽略 → 保存 DRAFT；
   - **试算**：任选 3~5 个户型看分数与排名变化，确认合理后「发布」（发布后只读，历史评测不变）。
4. **销控维护**：`下载模板 → 填表 → 导入`，失败行可下载错误明细；单套改状态需填原因（审计留痕）。
5. **看板**：预约量、确认率、到访率、爽约率、楼盘分布。

## 十、常见问题（FAQ）
| 问题 | 处理 |
| --- | --- |
| 评估点下去只有一两个维度有分 | 该户型参数不完整（多为房间窗面积未录）。看黄色"数据不足 n 项"提示；管理员按 §9.2 补录 |
| 分数比同楼盘另一户型低，但感觉更好 | 打开"切换模板"选贴合你家庭结构的模板；再点结论里的指标编号查权重差异；必要时用灵敏度分析看排名是否翻转 |
| 3D 打不开/卡顿 | 自动回落 2D；若仍想要 3D，用 Chrome、关闭其它 WebGL 页面，或在调试抽屉（管理员）用 AI 生成/模板版代码替换占位场景 |
| 锁定后没操作就没了 | 10 分钟自动释放（规则见 §4）。可重新锁定；如需更长，走"转意向"保留 24 小时 |
| 分享链接打不开 | 已过期或被撤销 → 重进"我的报告"重新生成；未登录可正常打开（只读不需登录） |
| 结论显示"模板生成" | AI 通道不可用（超时/额度/未配置）时的降级，逻辑仍按真实分数计算，可放心演示 |
| 数据从哪来 | 全部为按公开规范口径手工构造的演示数据（3 楼盘 / 20 户型 / 600 房源），执行 `database/seed-data.sql` 可重建 |

## 十一、环境与故障恢复
- 支持：Chrome / Edge 最新两版，≥1280px；手机 H5 支持浏览、收藏、评估、预约（3D/全景与锁房建议用电脑）。
- 演示地址与账号见课程提交包 `部署说明.md`；数据破坏时：`mysql -u… < database/schema.sql && … < database/seed-data.sql` 5 分钟内复原。
- 反馈与需求：项目仓库 issue / 组内组长；版本变更见 `constitution.md` 治理记录与 `docs/00-ROADMAP.md`。
