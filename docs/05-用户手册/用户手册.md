# 用户手册

演示账号：购房者 `13800000001` / `Test@123`，管理员 `admin` / `Test@123`。短信登录的验证码在演示环境固定为 `123456`。

## 1. 注册和登录

打开登录页可切换注册。口令至少 8 位且同时含字母和数字。连续失败 5 次锁定 15 分钟。登录后若画像完整度低于 60%，AI 顾问入口会要求先填写预算、家庭、居室和朝向。

## 2. 选房与户型

首页按居室、面积、朝向筛选。进入户型可看 2D 平面和 3D。3D 模型加载失败时回退为参数化盒体。

## 3. 评估

在户型页发起评估。页面给出等级、总分和分项证据。某一项显示「数据不足」表示原始字段没填，不影响其他项。评估结果仅供参考，不构成购房建议。

## 4. 对比与分享

把 2～4 个户型加入对比后生成矩阵。分享链接 7 天内可打开，页面不含手机号。需要纸质或 PDF 时，点「打印 / 另存 PDF」，在浏览器打印对话框里选择另存为 PDF。

## 5. 锁房与预约

锁定前必须勾选说明。成功后按服务端到期时间倒计时，可续期、取消或转意向。冲突时系统给出其他可售房源。预约选择有余量的时段；顾问在「预约」页推进状态。

## 6. 管理端

管理员登录后打开「管理」：

- 规则：看到当前版本。文件种子只读，先「复制为草案」再改权重（合计必须为 1），然后发布。标成 AI 的草案必须点「确认并发布」。
- 销控：按房源编号改状态，原因必填。可下载 Excel 模板再导入，失败行会提示行号。
- 用户：停用/启用、重置口令。列表里的手机号已打码。

顾问只能看到销控，规则和用户按钮不出现。预约处理走「预约」页。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| AI 显示模板回落 | 密钥未配置、超时或模型没返回 JSON。把 `LLM_ENABLED` 设为 false 可固定走模板，适合断网答辩。 |
| 顾问按钮是灰的 | 画像完整度不足 60%，先保存画像。 |
| 分享打不开 | 超过 7 天或令牌不对，请重新分享。 |
| 3D 空白 | 使用 Chrome，或直接看 2D。 |
