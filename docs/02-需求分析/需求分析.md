# 02 需求分析

图源：`docs/diagrams/dfd.mmd`（DFD-00 顶层、DFD-1 第一层）。

## 1. 现有售楼流程与目标流程

现有：顾问口头介绍 → 看沙盘和户型图 → 口头比较 → 纸质销控 → 约看房。

目标：购房者自己筛选户型并看到每条分数的依据 → 对比 2～4 个户型 → 锁定意向 → 预约时段。顾问在后台改销控、处理预约。管理员发布评分规则。

## 4. 用例规约（3 个主用例）

**UC-评估户型。** 参与者：购房者。前置：户型已入库。基本流：打开户型 → 评估 → 系统按当前规则计算 7 维 → 展示总分、雷达和证据。异常：某指标缺字段，该指标显示「数据不足」，维度内对其余指标归一，不把整单打成 0 分。

**UC-锁定房源。** 参与者：购房者。前置：已登录，房源可售，已勾选规则说明。基本流：提交锁定 → 行锁 + 条件更新 → 返回意向号和倒计时。异常：他人已锁，返回冲突和备选房源。并发：同一房源只有一人成功。

**UC-预约看房。** 参与者：购房者、顾问。基本流：选时段 → 容量未满则创建待确认单 → 顾问改为已确认/到访/完成/取消。异常：同时段已满，拒绝并提示。
