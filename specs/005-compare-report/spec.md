# SPEC 005 · 多户型对比与评估报告（创新点 I2）

**版本**: v1.0 | **状态**: Approved | **对应题目**: 核心模块 4「对比报告模块」
**报告落点**: `docs/03-概要设计` §3.5、`docs/04-详细设计` §5（矩阵生成与结论算法）、`docs/05` §7

## 1. 目标（WHY）
单个户型的 87 分本身没有决策价值，"A 和 B 之间我该选谁"才是。本域把 004 的评分矩阵化、差异高亮、
生成可导出可分享的结论文档，让用户带着判断去售楼部。

## 4. 验收标准

- **AC-40** Given 勾选 1 个户型，When 点"对比"，Then 按钮禁用且提示"至少选择 2 个"。
- **AC-41** Given 勾选 5 个，Then 返回 `40016`，前端提示上限 4。
- **AC-42** Given 矩阵，When 查看 `LIGHT_wfa` 行，Then 最优列绿色高亮并显示"+0.03 优于第二名"；差值口径为绝对差（比率类）或百分比（金额类）。
- **AC-43** Given AI 超 8s 未返回，When 生成结论，Then 降级模板结论、`aiGenerated=false`、页面标注"结论由规则模板生成（AI 暂不可用）"，报告仍可导出。
- **AC-44** Given 已保存报告，When 规则集发布新版本后重开，Then 显示的仍是创建时 `setVersion` 的矩阵与结论（不跟随最新规则）。
- **AC-45** Given 分享链接 `?token=`，When 未登录访问，Then 只读渲染成功；When `expire_at` 过期或用户撤销，Then `40304`。
- **AC-46** Given 分享页与 PDF，Then 不含手机号明文、不含其他用户隐私字段（NFR-13）。
- **AC-47** Given 2 个户型 4 项指标缺失，When 对比，Then 缺失项显示"—（数据不足）"且不参与高亮与推荐结论的证据引用。

## 5. 范围外
Word/Excel 导出（本期仅 PDF + 网页）、报告协作评论、报价与折扣敏感信息、报告版本 diff。

## 6. 界面与交互要点
`/compare`（候选池抽屉 + 矩阵 + 结论卡）、`/reports`（我的报告，含"已查看 N 次"）、报告详情页两种（登录态 / 分享态同一组件不同数据源）。
移动端：只读渲染 + 导出 PDF 走系统分享。

## 7. 数据与依赖
读 `evaluation`（004）+ 户型参数（002）；写 `compare_report`；被依赖 006（"带这份报告去看房"入口）、007（结论生成通道）。
