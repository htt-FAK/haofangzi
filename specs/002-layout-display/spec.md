# SPEC 002 · 户型展示（2D / 3D / 全景）

**版本**: v1.0 | **状态**: Approved | **对应题目**: 核心模块 1「户型展示模块」+ 创新点 I4
**报告落点**: `docs/02-需求分析` §2.2、`docs/04-详细设计` §3.2（Canvas 绘制算法）、`docs/05-用户手册` §3

## 1. 目标（WHY）
纸质户型图信息碎片化、销售话术不可核验。本域把户型"看得懂"这件事做到位：
尺寸标注可读、空间关系直观、朝向可判、装修效果可看，并为 004 打分提供**结构化几何数据**（不只是图片）。

## 4. 验收标准

- **AC-10** Given 98㎡ 三房户型，When 打开 2D 视图，Then 每个房间显示名称、面积（保留 1 位小数）与长×宽，且各房间面积之和与 `private_area` 偏差 ≤ 3%。
- **AC-11** Given 2D 视图，When 点击"主卧"，Then 主卧区域填充高亮 + 侧栏显示其窗面积与窗地比，且评分明细中 `LIGHT_bedroom` 行同步高亮。
- **AC-12** Given 3D 视图，When 旋转/缩放并在漫游模式下前进，Then 帧率 ≥ 30fps（演示机）、首屏可交互 ≤ 3s（NFR-02）。
- **AC-13** Given 无 GLB 模型，When 进入 3D 视图，Then 由参数化算法生成盒体且总占地包围盒与 2D 一致（±2%）。
- **AC-14** Given `pano_url` 加载失败，When 进入全景 Tab，Then 500ms 内显示降级提示与 2D 户型图，控制台无未捕获异常。
- **AC-15** Given 管理员录入房间坐标越界，When 保存，Then 返回校验错误并定位到具体房间行。
- **AC-16** Given 户型列表接口 `page=1,size=20`，When 并发 50，Then p95 ≤ 500ms 且总数正确（NFR-01）。

## 5. 范围外
真实 CAD 图纸解析（DXF/DWG）、构件级 BIM 精模、光照渲染烘焙、VR 头显适配、自由软装摆放。
以上写入 `docs/00-ROADMAP.md` 作为后续方向。

## 6. 界面与交互要点
`/project/:id`（楼盘 + 户型卡片瀑布）、`/house-type/:id`（Tab：2D 图纸 / 3D 空间 / 720° 全景 / 参数表 / 楼层剖面）、
右上角常驻"评分"按钮（跳 004）。移动端仅 2D + 参数表。

## 7. 数据与依赖
读 `hf_house_type`、`hf_room`、`hf_building`、`hf_project`；静态资源走文件服务签名 URL。
被依赖：003（选房时展示对应户型）、004（几何参数是唯一输入源）、005（报告内嵌 2D 缩略图）、007（AI 生成 3D 代码的宿主视图）。
